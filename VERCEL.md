# Как выложить «Сличение» на Vercel бесплатно

Тариф Hobby бесплатный, карта не нужна. Сайт будет работать в режиме «только просмотр»:
афоризмы, поиск, фильтры, авторы, темы, эпохи, сравнение. Вход, реакции, комментарии и мысли отключены.

## Способ 1. Через GitHub (проще всего)
1. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий (Public или Private).
2. Нажмите «uploading an existing file» и перетащите ВСЁ содержимое этой папки
   (app.py, slichenie.db, static, templates, data, requirements.txt, vercel.json и остальное).
3. Зарегистрируйтесь на vercel.com через «Continue with GitHub» и выберите тариф Hobby.
4. Add New → Project → выберите репозиторий → Deploy. Настройки не трогайте.
5. Через минуту получите адрес вида https://ваш-проект.vercel.app.

## Способ 2. Через командную строку
1. Установите Node.js, затем: `npm i -g vercel`
2. В этой папке выполните `vercel` и ответьте на вопросы (вход по почте или GitHub).
3. Для публичного адреса: `vercel --prod`.

## Если что-то пошло не так
- Ошибка сборки: проверьте, что в корне лежат app.py и requirements.txt.
- Страницы пустые: убедитесь, что slichenie.db загружен (≈2,8 МБ). GitHub принимает файлы до 25 МБ через браузер.
- Корзина сравнения хранится в cookie браузера, это нормально.
